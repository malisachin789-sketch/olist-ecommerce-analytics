## 📌 Project Overview
Analyzed **96,478 real orders** from Olist
Brazilian E-Commerce platform across
**8 interconnected tables** to identify
revenue trends, customer behavior,
and delivery performance.

## 🗂️ Dataset
| Detail | Info |
|--------|------|
| Source | Olist Brazilian E-Commerce — Kaggle |
| Orders | 96,478 |
| Tables | 8 |
| Period | 2016 – 2018 |
| Market | Brazil |

## 🛠️ Tools Used
| Tool | Purpose |
|------|---------|
| MySQL | 12 Business SQL Queries |
| Python | EDA + RFM Analysis |
| Power BI | Editorial Style Dashboard |

## 📊 Key Business Insights
1. **97% customers = one-time buyers**
   *(Critical retention gap identified)*
2. SP state = **48% of total revenue**
3. Credit card = **78% of all payments**
4. On-time delivery rate = **91.9%**
5. Express delivery earns **4.6 stars**
   vs 3.2 stars for slow delivery
